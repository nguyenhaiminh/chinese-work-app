# Hanzi Work

Ứng dụng web học tiếng Trung HSK 1–3 dành cho người đi làm. Nội dung tập trung vào từ vựng, cấu trúc, giao tiếp công sở và bài tập ngắn có giải thích.

## Chạy local

Mở `index.html` trực tiếp trong trình duyệt hoặc chạy một static server bất kỳ.

## Công nghệ

- HTML, CSS và JavaScript thuần
- Không cần cài dependency
- Lưu tiến độ bằng `localStorage`
- Phát âm bằng Web Speech API
